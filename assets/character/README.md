# キャラクター素材

DeskMate のキャラクターは **30×30 ピクセルのドット絵のティラノサウルス**です。

## ファイル

| ファイル | 対応する状態 | フレーム数 | 1 周 | 動き |
|---------|------------|:---------:|:----:|------|
| `running.gif` | `focused`（集中） | 10 | 900 ms | 脚を交互に動かして走る。尻尾を振り、土煙が出る |
| `sitting.gif` | `idle`（非集中） | 10 | 1600 ms | 座って呼吸。ときどき瞬きし、尻尾を揺らす |
| `sleeping.gif` | `away`（離席中） | 10 | 2000 ms | 寝そべって目を閉じ、Z が昇る |
| `break.gif` | 休憩促し | 10 | 1100 ms | 跳ねながら手を振り、「!」と「✦」が交互に出る |

すべて **透過 GIF・`loop=0`（無限ループ）・9 色パレット**。

```
frames/<action>/00.png .. 09.png   個別フレーム（1 枚だけ描き直したいとき用）
preview_<action>.png               8 倍拡大のフレーム一覧
preview_all.png                    4 アニメーションの一覧
```

## 表示するときの注意

1. **必ず最近傍補間で拡大する**（Qt なら `Qt.TransformationMode.FastTransformation`）。
   滑らかな補間を使うとドット絵が崩れて汚くなる。
2. **整数倍のみ**。30px の 4 倍 = 120px、5 倍 = 150px、6 倍 = 180px。
   非整数倍はピクセルの大きさが不揃いになる。
3. 背景は透過のまま使う。ウィジェットの背景色を透かす。
4. アニメーションの切り替えにフェードなどの演出を入れない。即座に切り替える。

## 作り直し・調整

```bash
python tools/make_character_gifs.py
```

Pillow が必要（`pip install pillow`）。**生成時だけ**必要で、アプリの実行には不要。
アプリは QMovie で GIF を再生するだけなので Pillow に依存しない。

スプライトは `tools/make_character_gifs.py` の中に ASCII アートとして定義してある。

| 定数 | 内容 |
|------|------|
| `PALETTE` | 9 色。`.` が透明 |
| `BODY` | 頭・首・胴（腕と脚と尻尾の先を除く） |
| `TAIL_TIP` | 尻尾の先端。独立させてあるので全アニメで振れる |
| `BELLY` | お腹の明るい部分 |
| `ARM` | 前肢 |
| `_leg_block()` | 脚をパラメータ（位置・長さ）から生成する |
| `frame_*()` | 各アニメーションの 1 フレームを組み立てる |

## 差し替え

本物のイラストに差し替える場合は、同じファイル名で 30×30 の透過 GIF を置けばよい。
サイズを変える場合は `character.scale` の整数倍前提が崩れないか確認すること。
